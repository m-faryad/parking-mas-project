# Data dictionary

All data are **synthetic** (generated by `parking_mas.datagen`). Origin: G = generated, C = configured, K = calculated.

## Arrivals CSV (`data/sample/sample_arrivals.csv`, generator output)
| Field | Meaning | Unit / valid values | Origin |
|---|---|---|---|
| vehicle_id | unique id | `V00000`… | G |
| arrival_min | request time | simulated min ≥ 0 | G |
| duration_min | intended parking duration (starts at allocation) | min, within [min,max] config | G |
| vehicle_type | requirement class | standard / ev / accessible | G |
| patience_min | max waiting time before leaving (0 = leaves at once) | min ≥ 0 | G |
| max_walk_m | longest walk the driver accepts | m > 0 | G |

## results/<run>/runs.csv – one row per run (scenario × strategy × replication)
Keys: `scenario, strategy, replication, seed` (C), `mode`. Metrics as in metrics.md (K). `wall_clock_s` and `mean_decision_ms` are non-deterministic (real time).
Also `valid_requests, invalid_requests, successful_requests, failed_requests, pending_requests, fail_*, total_wait_min, messages_total, total_capacity` (K).

## occupancy_timeseries.csv
`scenario, strategy, replication, seed, time` (simulated min), `occupied, capacity, occupancy_ratio, queue_length, occ_<car park>` (K).

## decision_log_replication0.csv (replication 0 only, to limit size)
`scenario, time, vehicle_id, vehicle_type, strategy, attempt (first|retry), n_candidates, candidates (ids considered), offers_declined, outcome, space_id, car_park, score, reason, compute_us` (K).
Failed retry attempts are not logged individually; the final failure appears as an event with its reason.

## summary_by_scenario.csv, comparison_paired.csv, tables.md
Aggregates (mean, sd, 95% t-CI, n) and paired differences (coordinated − baseline): `mean_diff, ci95_*, cohens_dz, p_ttest, p_ttest_holm, p_wilcoxon, note`. Empty = not computable.

## metadata.json
data_origin, package/library versions, mode, scenarios, strategies, replications, base_seed, seed_rule, nondeterministic_columns.

## Scenario JSON (configs/scenarios/*.json)
Fields of `ScenarioConfig`/`CarParkConfig` in `src/parking_mas/config.py` (demand model, durations, shares, patience, walk limits, car parks, strategy weights, emission factors). Validation rules are in `validate_config`.
